# Revamp design mocks

This folder holds the desktop design mocks for the perf-coach revamp, so every revamp issue can
point at a stable file path and each phase checkpoint can compare the running app against them.

[INDEX.md](INDEX.md) lists every screen with its source, preview, screenshot and the phase that
builds it.

## What's here

| Folder | Contents | Edit? |
|---|---|---|
| `mocks/source/` | The `.dc.html` files and `canvas.json` from the claude.ai design canvas, byte-for-byte | **Never.** Refresh from the canvas instead. |
| `mocks/preview/` | One standalone `.html` per screen that opens in any browser | Generated by the script |
| `mocks/screenshots/` | One full-page PNG per screen, 1440 px wide at 2x | Generated by the script |

Source canvas: https://claude.ai/artifact/A4mkZcnD7JC55tQe8SCpYZ

A `.dc.html` file only renders inside the canvas (it loads a `support.js` that isn't ours). The
screens are static, so `scripts/revamp_mock_preview.py` builds each preview by removing the canvas
wrapper: the `<helmet>` font link and styles move into `<head>`, the `<x-dc>` element is
unwrapped, the canvas scripts are dropped, and links between mocks point at the other previews.
Nothing else changes.

## How issues should use the mocks

- **The mock owns** layout, hierarchy, copy tone, colours and spacing.
- **The issue owns** numbers, formulas and rules. Where the mock and the issue disagree, the issue
  wins.
- **Numbers in the mocks are illustrative.** Some are deliberately inconsistent across screens:
  Home is dated Thu 12 Nov with Bangsaen42 as the A race; Training and Performance are dated
  Sun 8 Nov; the Plan screen shows Bangsaen21 as the A race. Don't copy mock values into fixtures
  or seed data.
- **Desktop only.** Mobile is designed later.
- Link to a screen by its path, for example
  `docs/revamp/mocks/screenshots/TrainingLog.png` for a quick look and
  `docs/revamp/mocks/preview/TrainingLog.html` for the exact markup and styles.

## How to refresh

When the mocks change in the canvas:

1. Re-read the artifact's `project/*.dc.html` files and `project/canvas.json` into
   `mocks/source/`, unchanged. Skip `TrainingCalendar.dc.html`.
2. Re-run the preview script and retake the screenshots (from the repo root):

   ```sh
   python scripts/revamp_mock_preview.py --screenshots
   ```

   Without `--screenshots` it only rebuilds the previews. Screenshots need Playwright with
   Chromium (`playwright install chromium`).
3. Check that no preview contains `<x-dc`, `<helmet` or `{{`; the script refuses to build if one
   does, or if a mock contains `{{…}}` holes or `<sc-for>` / `<sc-if>` logic.
4. Update [INDEX.md](INDEX.md) if screens were added, removed or moved to another phase.
