Column order becomes stack order
Desktop reads left column then right. Mobile has one column, so the two interleave by priority: morning → today's workout → coach → weight → race → performance → readiness → training → week plan → recent. Today's workout jumps up to second because on a phone it's the thing you open the app for.
Morning rows go two-line
Desktop fits icon, text and controls on one row. At 390 px the controls drop to their own line and go full width — Log 87.6 kg states the value it will save, and the three habit chips split the width evenly so they're thumb-sized.
Same tint rule
Rows stay white; only the icon chip carries colour — amber weight, indigo session, green habits. Identical to desktop.
Everything else is the same component
Today's workout, coach, weight sparkline, race countdown with its season bar, the two-tile readiness with details ▾, training bars, week plan rows and recent workouts all render from the same data at both sizes. Only paddings and type scale shift.
Nav becomes a scroll strip
Five tabs don't fit at 390 px as pills with the brand and avatar. They move to a horizontally scrollable bar under the brand row, same pattern as the Training tab's sub-tabs.
